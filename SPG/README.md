SPG frontend scaffold

This repository contains a simple static scaffold for a frontend with separate client and admin sections.

Structure:
- client/        -- client-facing pages (billing, payment, confirmation)
- admin/         -- admin dashboard pages (pricing rule management)
- shared/        -- shared CSS, JS, and images

How to use:
1. Place this folder into your web server document root (XAMPP htdocs already shows c:\xampp\htdocs\SPG).
2. Open the pages in a browser, e.g. http://localhost/SPG/client/index.html or http://localhost/SPG/admin/index.html

Notes:
- This is a static HTML/CSS/JS scaffold. Integrate with your backend or templating system as needed.
- CSS and JS are minimal and intended as a starting point.
